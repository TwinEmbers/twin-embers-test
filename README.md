# Twin Embers — Version 4

Open `index.html` in Chrome or Edge after extracting the ZIP. Keep `styles.css`, `script.js`, and `assets/` in the same folder.

New: **My Routine** connects the Skin Discovery answers to products saved in My Cabinet. It shows morning/evening essentials, matched products and unlisted steps. All data stays in this browser using localStorage; no accounts or network requests.

To test: complete Skin Discovery; add Cleanser (Both), Moisturizer (Both), and Sunscreen (Morning) in My Cabinet; visit My Routine. Change or remove a product to see the results update.

Limitations: cabinet maximum 3 products; type/time matching only, no ingredient validation, no medical diagnosis. Browser storage may be lost if cleared; local files are not yet published online.
